# Quality Checklist V1

## Before validation

- [ ] Case has all required files.
- [ ] Source pack minimum is met.
- [ ] Freshness check exists for active case.
- [ ] Dominant phase has at least 3 evidence items.
- [ ] Each transition watch has at least 3 documented signals.
- [ ] Critical scores 4–5 are justified.
- [ ] Contradictions are noted.
- [ ] Rejected alternatives are listed when relevant.
- [ ] Public outputs contain no forbidden internal terms.
- [ ] LLM draft is not presented as validated analysis.

## Before publication

- [ ] Analyst validation status is `analyst_validated`.
- [ ] Evidence status is not weak.
- [ ] Confidence is not higher than evidence allows.
- [ ] Claims are dated where current status matters.
- [ ] The diagnosis is attackable and auditable.
