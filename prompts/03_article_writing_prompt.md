# Article Writing Prompt — Strategic Phase Analysis

Tu es un spécialiste de géopolitique, relations internationales, histoire, économie politique et méthodologie scientifique.

Tu dois écrire deux textes distincts à partir de la méthode **Strategic Phase Analysis**.

## Texte 1 — Article scientifique

### Titre provisoire

**Strategic Phase Analysis: A Heuristic Framework for Diagnosing Transformation Regimes in International Systems**

### Objectif

Présenter Strategic Phase Analysis comme une méthode heuristique contrôlée de diagnostic des régimes de transformation dans les systèmes internationaux.

### Contraintes

- Ton méthodologique, prudent, défendable.
- Ne jamais prétendre que les relations internationales obéissent aux lois de la physique.
- Présenter l’analogie métallurgique comme origine conceptuelle contrôlée.
- Utiliser les termes géopolitiques publics dans le corps du texte.
- Réserver la bijection complète à une annexe.
- Insister sur :
  - variables ;
  - phases ;
  - transitions ;
  - preuve ;
  - validation humaine ;
  - limites ;
  - falsifiabilité relative ;
  - usage sur cas P0.

### Structure attendue

1. Introduction
2. Problem: diagnosing transformation regimes
3. Methodological position
4. Core variables
5. Phase taxonomy
6. Transition watches
7. Evidence and validation rules
8. Application logic
9. Limits
10. Annex: internal conceptual correspondence

## Texte 2 — Article type Conflits

### Titre provisoire

**Lire les phases de la puissance : comment les crises transforment les ordres géopolitiques**

### Objectif

Faire comprendre à un lectorat stratégique que certains ordres ne sont pas seulement stables ou instables : ils changent de régime.

### Contraintes

- Ouverture analogique brève.
- Ensuite vocabulaire géopolitique uniquement.
- Pas de jargon métallurgique dans le corps.
- Style clair, incarné, stratégique.
- Cas à utiliser :
  - Mer Rouge / Bab el-Mandeb ;
  - Ormuz ;
  - Taïwan ;
  - Ukraine / mer Noire.

### Structure attendue

1. Accroche
2. Pourquoi “stable / instable” ne suffit pas
3. Les six phases géopolitiques
4. Comment les crises ferment ou rouvrent les options
5. Corridors et chokepoints comme lignes de contrainte
6. Quatre cas courts
7. Ce que la méthode change pour l’analyse stratégique
8. Conclusion
