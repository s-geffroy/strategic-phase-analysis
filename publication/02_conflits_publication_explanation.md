# Conflits Publication Explanation

## Proposed title

**Lire les phases de la puissance : comment les crises transforment les ordres géopolitiques**

## Core angle

Certains espaces internationaux ne sont pas simplement stables ou instables. Ils changent de régime.

Une interdépendance commerciale peut se stratifier, se durcir, se fissurer ou devenir coercitive sous l’effet des crises, des rivalités et des dépendances critiques.

## Style

- Clair.
- Stratégique.
- Incarné par des cas.
- Pas de surcharge méthodologique.
- Une analogie brève en ouverture, puis vocabulaire géopolitique.

## Concepts publics à utiliser

- phase absorbante ;
- phase transformative ;
- phase stratifiée ;
- phase résiliente ;
- phase cassante ;
- phase coercitive locale ;
- délamination coercitive ;
- stabilisation post-crise ;
- fissuration systémique.

## Cas recommandés

1. Mer Rouge / Bab el-Mandeb : délamination coercitive d’un corridor.
2. Ormuz : capacité de durcissement sous choc énergétique.
3. Taïwan : phase transformative à haut carbone stratégique.
4. Ukraine / mer Noire : fatigue, durcissement et contraintes logistiques.

## Phrase directrice

La question n’est pas seulement de savoir si une crise s’aggrave ou se calme. La vraie question est de savoir quel type d’ordre elle laisse derrière elle.
