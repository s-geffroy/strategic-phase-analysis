# Publication Vocabulary Rules

## Principe

Le vocabulaire métallurgique explique la genèse et la structure interne de la méthode. Il ne doit pas envahir les diagnostics publics.

## Publication scientifique

Autorisé :
- explication courte de l’origine analogique ;
- annexe méthodologique avec bijection ;
- discussion des limites de l’analogie.

Obligatoire :
- préciser que la méthode est heuristique ;
- refuser toute prétention de loi physique ;
- documenter validation, preuves et limites.

## Publication type Conflits

Autorisé :
- ouverture analogique brève.

Ensuite :
- vocabulaire géopolitique uniquement ;
- cas concrets ;
- style stratégique clair ;
- pas de bijection complète dans le corps.

## Diagnostics publics

Interdits :
- ferritique ;
- austénitique ;
- perlitique ;
- bainitique ;
- martensitique ;
- cémentitique ;
- ferritic ;
- austenitic ;
- pearlitic ;
- bainitic ;
- martensitic ;
- cementitic.
