# Internal / Public Bijection

## Usage

Ce fichier est interne ou scientifique-annexe uniquement. Les diagnostics publics doivent utiliser exclusivement les libellés géopolitiques.

## Bijection dure

| Internal phase | phase_id public |
|---|---|
| ferritic | absorptive_institutional_order |
| austenitic | active_transformation_order |
| pearlitic | stratified_interdependence_order |
| bainitic | resilient_security_order |
| martensitic | brittle_coercive_order |
| cementitic | localized_coercive_nodes |

## Règle

Chaque phase interne possède un seul équivalent public, et chaque phase publique renvoie à une seule phase interne.

Aucun alias ne peut remplacer les `phase_id` canoniques.
