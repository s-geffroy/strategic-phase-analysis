# Method Specification — Strategic Phase Analysis V1

## 1. Définition

Strategic Phase Analysis est une méthode de diagnostic des régimes de transformation géopolitique. Elle identifie la phase dominante d’un système, ses phases secondaires, ses modificateurs, ses signaux de transition, ses contraintes internes et son risque de durcissement, de résilience ou de rupture.

La méthode ne prétend pas être une théorie totale des relations internationales. Elle sert à diagnostiquer des configurations stratégiques comparables : crises, corridors, chokepoints, théâtres régionaux, acteurs, alliances, institutions et dépendances critiques.

## 2. Statut

- **Public :** méthode autonome de diagnostic géopolitique.
- **Interne :** module transversal compatible avec Strategic Flow Dynamics et les moteurs d’analyse des corridors, chokepoints, crises et dépendances critiques.

## 3. Unité d’analyse

La méthode est multi-échelle :

1. système global ;
2. théâtre régional ;
3. crise stratégique ;
4. corridor / chokepoint ;
5. acteur / bloc ;
6. alliance / institution ;
7. chaîne de dépendance critique.

La V1.0 teste prioritairement les **crises** et les **corridors / chokepoints**.

## 4. Variables centrales

### 4.1 Température géopolitique

La température géopolitique mesure l’énergie active de transformation d’un système.

Composantes :
- tension militaire ;
- pression économique ;
- volatilité politique ;
- intensité diplomatique ;
- guerre informationnelle ;
- stress logistique ;
- urgence sociale ;
- accélération technologique ;
- densité d’incidents ;
- perception de menace.

### 4.2 Carbone géopolitique

Le carbone géopolitique mesure la capacité d’un système à se durcir rapidement sous choc.

Composantes :
- puissance coercitive ;
- conflictualité latente ;
- rivalité stratégique ;
- mémoire historique non résolue ;
- dépendances critiques ;
- rigidité idéologique ;
- faible ductilité institutionnelle.

### 4.3 Refroidissement géopolitique

Le refroidissement géopolitique mesure la vitesse à laquelle les options se ferment ou se stabilisent après une phase chaude.

Composantes :
- vitesse de désescalade ;
- fermeture ou réouverture des options diplomatiques ;
- gel des positions militaires ;
- institutionnalisation du nouvel ordre ;
- normalisation économique ;
- maintien ou levée des sanctions ;
- consolidation des récits politiques ;
- création ou destruction de canaux de confiance ;
- acceptation ou contestation du nouveau statu quo.

## 5. Traitements historiques et opérateurs

Les traitements sont utilisés comme opérateurs de transformation :

- recuit stratégique : réduction des contraintes internes, réouverture diplomatique ;
- trempe stratégique : fermeture rapide des options, durcissement coercitif ;
- revenu post-crise : réduction de la fragilité sans annuler tout le durcissement ;
- écrouissage stratégique : durcissement par contraintes répétées ;
- fatigue systémique : perte de résilience après sollicitations répétées ;
- corrosion interne : dégradation de confiance, cohésion, légitimité ou fiabilité institutionnelle.

## 6. Sorties V1

Chaque cas produit :

1. fiche courte de diagnostic ;
2. fiche analytique complète ;
3. bloc machine YAML ;
4. synthèse décisionnelle ;
5. evidence notes ;
6. validation log.

## 7. Validation humaine

Le LLM peut proposer. Il ne valide jamais.

Toute phase finale doit être validée par un analyste avec :
- justification ;
- preuves ;
- incertitudes ;
- alternatives rejetées ;
- statut de preuve ;
- niveau de confiance.
