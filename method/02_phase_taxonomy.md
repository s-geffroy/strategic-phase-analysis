# Phase Taxonomy V1

## Principe

Les phases publiques sont géopolitiques. Les termes internes ne doivent pas apparaître dans les diagnostics publics.

Chaque phase possède :
- un `phase_id` stable en anglais ;
- un libellé court français ;
- un libellé complet français ;
- un libellé anglais ;
- un équivalent interne unique.

## Définitions

### Phase absorbante — ordre institutionnel absorbant

Configuration dans laquelle les tensions sont principalement absorbées par des institutions, normes, interdépendances, routines diplomatiques ou mécanismes de négociation.

### Phase transformative — ordre de transformation active

Configuration dans laquelle le système est fortement énergisé et peut changer rapidement de structure, d’alliances, de règles, d’équilibres ou de trajectoire.

### Phase stratifiée — ordre d’interdépendance stratifiée

Configuration dans laquelle coopération et rivalité coexistent en couches distinctes : commerce, sécurité, technologie, énergie, diplomatie ou normes.

### Phase résiliente — ordre de sécurité résiliente

Configuration stabilisée après choc, plus sécuritaire et plus durcie, mais encore gouvernable par institutions, garanties, canaux diplomatiques ou équilibre de dissuasion.

### Phase cassante — ordre coercitif cassant

Configuration rapidement rigidifiée par choc, forte polarisation, fermeture des options diplomatiques, prédominance de la coercition et risque élevé de rupture.

### Phase coercitive locale — noyaux de coercition fragile

Structures localisées de contrainte dure : zones militarisées, appareils sécuritaires, dispositifs de sanctions, milices, doctrines fermées, points de verrouillage ou infrastructures sous contrôle coercitif.

## Modificateurs V1

| modifier_id | Libellé FR | Sens |
|---|---|---|
| polyphased | polyphasé | plusieurs régimes coexistent dans le même cas |
| metastable | instable mais contenu | équilibre provisoire, réactivation possible |
| fragmented_under_constraint | fragmenté sous contrainte | lignes de rupture déjà visibles |
| degraded_from_within | dégradé de l’intérieur | confiance, cohésion ou légitimité affaiblie |
| hardened_by_repeated_stress | durci par contrainte répétée | perte progressive de souplesse |
| weakened_by_repeated_stress | affaibli par sollicitations répétées | résilience réduite |
| over_normalized | normalisé mais émoussé | stabilisé, mais peu réactif |
| unstructured | désorganisé non structuré | absence de configuration stable |
